🚀 Deploy Process (GitHub Pages)

⚠️ Critical: Always use --rejoin before the second split call to bust the stale hash cache. Reusing a branch name points to an old hash and the push silently does nothing. Always push the raw commit hash directly.

# Standard deploy workflow (run from BOB root: C:\Users\000I7A744\Desktop\BOB)
git add Website/<changed files>
git commit -m "feat/fix: description"

# Bust the subtree cache, then split and push by hash
git subtree split --prefix=Website HEAD --rejoin 2>&1 | Out-Null
$hash = git subtree split --prefix=Website HEAD
git push craftyblooms "${hash}:refs/heads/main" --force
Remotes: origin → BOB monorepo  |  craftyblooms → https://github.com/swapnilk-dev-git/craftyblooms.git (GitHub Pages source)

⚠️ Known Limitations & Gotchas

#IssueWorkaround / Notes
1Cross-device order sync — FIXED Google Sheets backend syncs orders across all devices once GAS_URL is set.Deploy Code.gs as an Apps Script Web App → paste URL into GAS_URL in both catalog.js and admin.js.
2Subtree split cache — reusing a branch name re-points to old hash, push is a no-op.Always use --rejoin flag + push raw hash. Never reuse branch names.
3CSS custom properties in inline styles — var(--red) doesn't work in element.style.borderColorUse hardcoded hex #C8102E in JS for inline border colors.
4localStorage 5MB limit — base64 uploaded images (via product editor) fill it fast.Use relative Images/ paths for default products. Only upload small images via editor.
5No WhatsApp API for sending to customers — cannot send programmatically without Meta Business API approval.Admin uses "Send Confirmation" button which pre-fills a WA message the admin sends manually.
6New-order notification poller is same-device only — FIXED With Sheet backend, syncFromSheet() fetches live data on every 10s poll + tab focus.Requires GAS_URL to be set.
7GIFTWRAP_THRESHOLD must be declared before openOrderForm()Declared at line 312 in catalog.js — do not move it below line ~340.

🔐 Admin Flow

1
Open admin.html → enter PIN 1234 → locked out after 3 wrong attempts for 5 minutes.
2
Dashboard shows stats. Pulsing red badge on "Pending" card when new orders arrive.
3
Accept ✅ or Reject ❌ an order → auto-prompt to send WA confirmation to customer.
4
Green "📲 WhatsApp" button on each order → pre-fills message with order details + status. Admin taps Send.
5
Add internal admin notes. Export all orders as CSV. Delete individual or clear all orders.
6
Click "✏ Edit Store" → opens index.html?edit=1 → catalog auto-enters admin edit mode.
7
In edit mode: hover any card → ✂ Crop / ✏ Edit buttons appear. Edit drawer: name/price/MRP/desc/featured/stock/images. Add new products with + button. Exit with red ✕ button.

🛍 Customer Order Flow

1
Browse catalog → use qty stepper (− 1 +) on card → click "Add to Cart"
2
Cart drawer opens (or tap bottom bar) → review items, qty steppers, gift-wrap progress bar
3
Click "Place Order" → fill Name + Phone + Delivery Address (+ optional note) → cart summary shown
4
Submit → Order logged to localStorage → WhatsApp opens with pre-filled order message to +91-7030261766
5
Admin sees order card → Accepts/Rejects → sends WA confirmation back to customer
